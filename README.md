#🧑‍💻 Priyanshu Pandey — Portfolio 2024
"Turning ideas into clean, modern web experiences." > A high-performance personal portfolio showcasing creative design, front-end craftsmanship, and academic excellence.

✨ Key Features
🕹️ Immersive Hero Section: Featuring a canvas-based background animation and a 3D floating avatar scene with CSS-driven orbital paths.

🤖 PandeyG AI Bot: A custom-integrated chatbot window to provide instant information about my background and availability.

🌓 Adaptive UI: Includes a smooth "Day Mode" toggle and custom cursor tracking for a premium user experience.

📊 Dynamic Stats: Real-time "Count-Up" animations showcasing academic achievements (9.1 CGPA) and project milestones.

📱 Fully Responsive: A mobile-first approach with a custom sidebar navigation and hamburger menu for smaller screens.

🛠️ Technical Breakdown
Frontend Architecture
Semantic HTML5: Structured for SEO and accessibility.

Modern CSS3: * CSS Variables: Centralized design tokens for colors (Red-soft, Red-glow) and themes.

Advanced Animations: Keyframe-heavy visuals including avatar3DFloat, orbitSpin, and shadowPulse.

Glassmorphism: Elegant sidebar and card designs using backdrop filters.

Vanilla JavaScript: Lightweight logic for the chatbot, theme switching, and scroll-reveal triggers.
